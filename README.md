# J & L Powertools LTD - Official Website

Welcome to the official repository for the J & L Powertools LTD website — a Nigerian-based showroom for premium **aluminium ladders**, **scaffolding**, and **industrial equipment**. This modern site is built using **Next.js** and includes key SEO optimizations for visibility across Nigeria and West Africa.

## 🌍 Live Website

[https://www.jlpowertools.biz](https://www.jlpowertools.biz)

## 🛠️ Tech Stack

- **Framework:** [Next.js](https://nextjs.org/)
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **SEO:** next-seo
- **Deployment:** Vercel
- **Data:** Local JSON (for articles and products)

## 📂 Project Structure

├── components/ # Reusable components (buttons, outline effects, etc.)
├── pages/ # Next.js routing pages
│ ├── index.tsx # Homepage
│ ├── about.tsx # About page
│ └── products.tsx # Product listings
├── public/ # Static files (images, favicon, etc.)
├── data/ # posts, products, testimonials (local JSON)
├── styles/ # Global styles
└── next-seo.config.js # SEO metadata defaults


## ✨ Features

- 🚀 Fully responsive and mobile-first design
- 🔍 SEO optimized with sitemap and `robots.txt`
- 🏗️ Product cards for scaffolding and ladders
- 📚 Article system (insights/blog) with dynamic routing
- 🗺️ Integrated Google Maps iframe for branch location
- 🌍 OpenGraph tags and meta previews

## 📦 Setup Locally

```bash
git clone https://github.com/byteprowler/jlpowertools.git
cd jlpowertools
npm install
npm run dev
visit: http://localhost:3000

```

## 📁 Important Files
